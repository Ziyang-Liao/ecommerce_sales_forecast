# Data Dictionary

This document defines the data field specifications for the sales forecasting system.

## Raw Data Fields (sales_history.csv)

| Field | Type | Description |
|-------|------|-------------|
| asin | string | Amazon Standard Identification Number |
| sku | string | Stock Keeping Unit, unique product variant identifier |
| marketplace | string | Sales marketplace (US/UK/DE/FR/IT/ES/CA) |
| date | datetime | Sales record date, format YYYY-MM-DD |
| sales_quantity | int | Daily sales quantity |
| sale_price | float | Actual selling price |
| original_price | float | Standard retail price / list price |
| discount_rate | float | Discount rate, 0.0~1.0 |
| ad_spend | float | Daily advertising spend |
| ad_impressions | int | Daily ad impressions |
| ad_clicks | int | Daily ad clicks |
| fba_inventory | int | FBA warehouse available inventory |
| is_lightning_deal | int | Lightning Deal participation (0/1) |
| is_coupon_active | int | Active coupon (0/1) |
| is_deal_of_day | int | Deal of the Day (0/1) |
| bsr_rank | int | Best Seller Rank |
| rating | float | Product rating (1.0~5.0) |
| review_count | int | Total review count |
| product_line | string | Product category |
| launch_date | datetime | Product launch date |
