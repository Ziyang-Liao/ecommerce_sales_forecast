## 字段详细说明

### 1. sku (SKU编号)

| 属性 | 值 |
|------|-----|
| 类型 | string |
| 必需 | ✅ 是 |
| 重要程度 | ⭐⭐⭐⭐⭐ |
| 示例 | LED-US-0001, SMART-DE-0023 |

**含义**: 库存单位编号，唯一标识每个产品变体。

**为什么需要**: 
- 作为分组键，每个SKU独立预测
- 不同SKU销售模式不同，需分开建模

**数据要求**:
- 不能为空
- 同一SKU的历史数据需连续

---

### 2. date (日期)

| 属性 | 值 |
|------|-----|
| 类型 | datetime |
| 必需 | ✅ 是 |
| 重要程度 | ⭐⭐⭐⭐⭐ |
| 格式 | YYYY-MM-DD |
| 示例 | 2025-01-15 |

**含义**: 销售记录的日期。

**为什么需要**: 
- 时间序列的时间维度
- 用于识别季节性、趋势、周期性

**数据要求**:
- 不能为空
- 建议每日一条记录（日粒度）
- 缺失日期需补0或插值

---

### 3. sales_quantity (销售数量)

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 必需 | ✅ 是 |
| 重要程度 | ⭐⭐⭐⭐⭐ |
| 范围 | >= 0 |
| 示例 | 0, 15, 328 |

**含义**: 当日销售的产品数量。

**为什么需要**: 
- **预测目标**，模型的核心输入和输出
- 所有预测都基于历史销量模式

**数据要求**:
- 不能为空，缺失填0
- 必须为非负整数
- 建议至少60天历史数据

---

### 4. marketplace (站点)

| 属性 | 值 |
|------|-----|
| 类型 | string |
| 必需 | ✅ 是 |
| 重要程度 | ⭐⭐⭐⭐ |
| 枚举值 | US, UK, DE, FR, IT, ES, CA, JP |

**含义**: Amazon销售站点/国家。

**为什么需要**: 
- 不同站点消费习惯不同
- 节假日、促销时间不同
- 需按站点分开预测

---

### 5. sale_price (售价)

| 属性 | 值 |
|------|-----|
| 类型 | float |
| 必需 | 建议 |
| 重要程度 | ⭐⭐⭐⭐ |
| 单位 | 当地货币 |
| 示例 | 29.99, 15.50 |

**含义**: 产品当日实际售价。

**为什么需要**: 
- 价格是影响销量的核心因素
- 降价促销会导致销量激增
- 可作为协变量提升预测准确率

---

### 6. original_price (原价)

| 属性 | 值 |
|------|-----|
| 类型 | float |
| 必需 | 可选 |
| 重要程度 | ⭐⭐⭐ |
| 单位 | 当地货币 |

**含义**: 产品标准零售价/划线价。

**为什么需要**: 
- 用于计算折扣力度
- 原价与售价差距影响购买决策

---

### 7. discount_rate (折扣率)

| 属性 | 值 |
|------|-----|
| 类型 | float |
| 必需 | 建议 |
| 重要程度 | ⭐⭐⭐⭐ |
| 范围 | 0.0 ~ 1.0 |
| 计算 | 1 - sale_price / original_price |
| 示例 | 0.25 (表示75折) |

**含义**: 当日折扣力度。

**为什么需要**: 
- 量化促销强度
- 折扣率与销量增幅强相关
- 大促期间折扣率是关键特征

---

### 8. ad_spend (广告花费)

| 属性 | 值 |
|------|-----|
| 类型 | float |
| 必需 | 建议 |
| 重要程度 | ⭐⭐⭐⭐ |
| 单位 | 当地货币 |

**含义**: 当日广告投放花费。

**为什么需要**: 
- 广告投入直接影响曝光和销量
- 广告策略变化会导致销量波动
- 是重要的可控变量

---

### 9. ad_impressions (广告曝光)

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 必需 | 可选 |
| 重要程度 | ⭐⭐⭐ |

**含义**: 当日广告展示次数。

**为什么需要**: 
- 反映产品曝光度
- 曝光量变化预示销量变化

---

### 10. ad_clicks (广告点击)

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 必需 | 可选 |
| 重要程度 | ⭐⭐⭐ |

**含义**: 当日广告点击次数。

**为什么需要**: 
- 反映用户兴趣度
- 点击率变化反映市场需求

---

### 11. fba_inventory (FBA库存)

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 必需 | 建议 |
| 重要程度 | ⭐⭐⭐⭐ |

**含义**: 当日FBA仓库可售库存数量。

**为什么需要**: 
- **关键**: 库存为0时销量必然为0
- 需识别缺货导致的销量下降
- 避免将缺货误判为需求下降

**数据要求**:
- 库存为0的记录需特别标注
- 预测时需考虑库存约束

---

### 12. is_lightning_deal (秒杀活动)

| 属性 | 值 |
|------|-----|
| 类型 | int |
| 必需 | 建议 |
| 重要程度 | ⭐⭐⭐⭐ |
| 枚举值 | 0 (否), 1 (是) |

**含义**: 当日是否参与Lightning Deal秒杀。

**为什么需要**: 
- 秒杀期间销量会暴增3-10倍
- 不标注会导致模型误判趋势
- 是重要的异常事件标记

---

|------|-----|

| 重要程度 | ⭐⭐⭐ |
| 枚举值 | 0 (否), 1 (是) |

**含义**: 当日是否有优惠券生效。

**为什么需要**: 
- 优惠券提升转化率

## 重要程度说明

| 等级 | 星级 | 含义 | 对预测的影响 |
|------|------|------|--------------|
| 必需 | ⭐⭐⭐⭐⭐ | 缺少则无法预测 | 核心输入，必须提供 |
| 强烈建议 | ⭐⭐⭐⭐ | 显著提升准确率 | 可提升5-15%准确率 |
| 建议 | ⭐⭐⭐ | 捕捉特殊事件 | 可提升2-5%准确率 |
| 可选 | ⭐⭐ | 锦上添花 | 边际提升<2% |

---

## 数据质量要求

### 完整性
- 必需字段不能为空
- 日期需连续，缺失日期补0

### 准确性
- 销量数据需与实际订单一致
- 价格需反映实际成交价

### 时效性
- 建议T+1更新（次日更新前一天数据）
- 历史数据建议保留2年以上

### 一致性
- 同一SKU的数据格式需统一
- 站点代码使用标准枚举值
